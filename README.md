## ✨ About

The **Diwali Wish Webpage** is a single-page celebration of the festival of lights, built as one self-contained HTML file. Open it and the page lights up with animated diyas and fireworks — a small digital greeting for Diwali, updated for **Diwali 2027 (Friday, 29 October 2027)**.

## 🚀 Features

- 🪔 **Animated diyas** — flickering lamps that light up the page
- 🎆 **Fireworks** — a colourful sky show in the browser
- 💌 **Wish cards** — festive greetings ready to share
- 📱 **One file, any device** — the whole page is a single HTML file, works on phone or computer, nothing to install

## 🛠️ Tech Stack

| Part | Technology |

| Page | HTML, CSS, JavaScript (single file) |
